
# MySQL Employee Database – Practice Assignment

## About the Assignment

This is a **MySQL practice assignment** created to practice basic SQL database concepts, including table creation, data insertion, constraints, and modifying table structures.

The assignment uses three related tables:

* **Departments** – Stores department details
* **Location** – Stores location details
* **Employees** – Stores employee information and connects employees with departments and locations

## Tables Used

### Departments

Contains:

* `department_id`
* `department_name`

### Location

Contains:

* `location_id`
* `location`

### Employees

Contains:

* `employee_id`
* `employee_name`
* `gender`
* `date_of_joining`
* `designation`
* `department_id`
* `location_id`
* `salary`
* `email`

## SQL Concepts Practiced

* `CREATE TABLE`
* `INSERT INTO`
* `ALTER TABLE`
* `ADD COLUMN`
* `MODIFY COLUMN`
* `DROP COLUMN`
* `RENAME COLUMN`
* `PRIMARY KEY`
* `FOREIGN KEY`
* `ENUM`
* `DECIMAL`
* Foreign Key Constraints

## Purpose

The main purpose of this assignment is to understand how to:

* Create relational database tables
* Define primary keys
* Establish relationships using foreign keys
* Insert records into related tables
* Modify existing table structures
* Add, modify, rename, and delete columns
* Understand and resolve foreign key constraint errors
